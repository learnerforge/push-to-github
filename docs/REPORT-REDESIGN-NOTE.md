## 3. What changed in the code

### `report.py`
- **CSS** → the complete dark-theme stylesheet (§4). Replaces the old light-theme inline block.
- **`generate()`** → new template; embeds the `CSS` constant; renders the dark frame, per-type card classes, and the five sections. The previous template referenced undefined `{BG}`/`{DIM}`/`{BEST}`/`{BAD}`/`{WARN}` variables — removed along with the old theme.
- **`_timeline()`** → rebuilt from `<tr>` table rows to `.tl-event` divs with icon chips, mono time, bold repo, muted detail, and a `↗` link rendered when the event carries a `url`.
- **`_details(sync_results, registry)`** → now takes the registry to resolve each repo's GitHub URL for the "Open on GitHub ↗" link; renders `.detail-block` cards with action badge, `N file(s) changed` stats + reason, `before → after` SHA line, and the `.file-table` status chips. Action→badge map: `pushed→badge-push`, `clean/committed→badge-ok`, `skipped/blocked→badge-warn`, `failed→badge-fail`.
- **`_all_repos()`** → extended table with a **Branch** column (from the reworked `_status_for_repo`) and repo links; status badges CLEAN/DIRTY/UNINIT.
- **`_status_for_repo(path)`** → now returns `(state, branch)` so the report can show the live branch alongside the working-tree state.
- **`_security()` / `_drift()`** → unchanged logic; their `section` markup now matches the dark theme automatically.

### `runner.py`
- **`_sync_events(results, registry)`** → sync events (pushed / failed / blocked / skipped) now carry the repo `url` from the registry, so the timeline's `↗` link works. Call site updated to pass the registry.
